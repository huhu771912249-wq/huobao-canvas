# 冠希无限画布视频素材生成操作说明

## 入口选择

首页先选视频类型，不要把两种流程混在一起：

- 文生视频：不需要图片，只输入画面、动作、镜头和风格。
- 图生视频：必须先上传首帧/参考图，再写动作提示词。

## 文生视频流程

1. 首页点击“文生视频”。
2. 在“视频提示词”节点填写内容，建议包含主体、场景、动作、镜头、节奏、风格。
3. 在“文生视频”配置节点选择模型、比例和时长。
4. 点击生成，等待任务完成。
5. 在“视频结果”节点预览并下载成片。

## 图生视频流程

1. 首页点击“图生视频”。
2. 在“首帧/参考图”节点上传图片。
3. 在“视频动作提示词”节点填写动作和镜头，不要只写风格词。
4. 在“图生视频”配置节点选择模型、比例和时长。
5. 点击生成，等待任务完成。
6. 在“视频结果”节点预览并下载成片。

## H3 广告 GIF 完整链路

在画布的“工作流”面板选择“H3 广告 GIF 完整链路”，会放入一组可单独替换、删除和重新连线的节点：

`Z-Image 文生图（可切 Krea 2 Turbo） → H3 首帧生视频 → 视频转 GIF → 可视化加字 → 水印编辑 → GIF 导出`

- H3 采样：`20 步标准` 是原生稳定模式；`4 步 Turbo` 为加速模式，需要服务器已安装 Turbo LoRA 与采样器。
- SeedVR2：`原生快速` 不超分，`智能判断` 仅在目标尺寸超过原片时超分，`AI 高清` 始终超分。
- H3 提示词：节点中的“使用官方 Skill 优化 H3 提示词”按 T2VA / I2VA 官方结构整理画面、声音和音乐。

## 提示词模板

```text
主体：需要动起来的对象
场景：背景和环境
动作：3-5 秒内发生什么变化
镜头：推进 / 拉远 / 横移 / 轻微摇镜 / 固定镜头
节奏：慢速 / 中速 / 快速
风格：真实广告 / 赛博 / 电影感 / 电商素材 / 卡通
画幅：16:9 / 9:16 / 1:1
限制：不要变形、不要多手、多脸、乱码文字、闪烁黑边
```

## 高转化素材模板

```text
主体保持清晰，画面中心稳定，背景轻微动态变化，镜头缓慢推进。
开头 1 秒突出卖点，中段强化点击欲望，结尾保留干净留白。
广告素材风格，高对比，高饱和，适合投流预览。
```

## 失败排查

- 没有图片：图生视频必须先上传首帧/参考图。
- 没有提示词：必须填写“视频提示词”或“视频动作提示词”。
- 生成后没结果：先看任务状态，只有成功并读到视频 URL 才算完成。
- 下载失败：优先从“视频结果”节点下载；没有 URL 时不要假装已完成。
