# 火宝画布生产收口设计

## 目标

把当前已上线但尚未完整版本化的火宝画布收口为可回滚、可维护的生产版本，并补齐安全登录、LTX 音频字幕合成和低门槛 API 设置。

## 范围

1. 整理并提交火宝画布前端源代码，排除密钥、缓存和系统文件。
2. 登录凭据只从服务器环境读取；增加失败限流、持久会话和安全 Cookie。
3. 建立 LTX 音频、字幕轨、视频合成和最终 MP4 下载的完整流程。
4. 默认隐藏 Base URL、API Key 和端点路径，把它们收进高级设置。
5. 通过自动测试、构建、服务器部署和公网真实操作完成验收。

## 架构

- 前端 Vue 继续负责画布交互、字幕编辑、任务进度、预览和下载。
- Python 素材 API 负责认证、任务编排和媒体合成；认证状态写入本地受限状态文件，凭据来自 systemd 环境文件。
- FFmpeg 负责将视频、LTX FLAC 和字幕渲染合成为 MP4，不在浏览器中进行高负载转码。
- Nginx 只负责 TLS、静态文件和反向代理，不再使用浏览器原生 Basic Auth。

## 认证设计

- 不允许代码内置生产密码。
- 登录失败按 IP 和用户名滑动计数，超过阈值返回 429。
- Session token 只保存哈希，状态文件权限限制为服务用户可读写。
- Cookie 使用 HttpOnly、Secure、SameSite=Lax，并保持 12 小时有效期。
- 服务重启后未过期会话仍有效；退出立即撤销。

## 媒体闭环

1. 用户选择或生成源视频。
2. 使用 LTX 生成音频，或选择已有音频。
3. 用户输入字幕文本；系统按音频时长均匀生成初始时间段，允许编辑。
4. 后端验证素材归属和格式，调用 FFmpeg 合成音轨并烧录字幕。
5. 前端轮询真实进度，完成后预览和下载 MP4；失败显示原因并允许重试。

首版不做语音识别自动转写，避免引入新的模型依赖。字幕内容由用户提供或复用画布文本节点。

## API 设置

- 默认页只显示渠道、模型和可用状态。
- 本地火宝渠道不显示 Key 或 Base URL。
- 其他渠道的技术配置折叠在“高级设置”，并保留现有自定义能力。

## 错误与恢复

- 认证、音频生成、字幕解析、FFmpeg、文件发布分别返回可识别错误码。
- 合成写入新的输出文件，不覆盖源视频和音频。
- 发布前保存远端代码、前端 dist、Nginx 和 systemd 配置备份。

## 验收

- 前端单元测试和生产构建通过。
- 后端认证与合成测试覆盖成功、未登录、限流、重启会话和非法媒体。
- 公网验证登录、刷新会话、LTX 音频、字幕合成、MP4 播放和下载。
- GitHub 提交不包含密钥、`.DS_Store`、生成媒体或服务器状态文件。
