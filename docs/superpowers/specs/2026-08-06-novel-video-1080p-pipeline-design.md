# 冠希小说成片与全链路 1080p 设计

## 目标

把现有“小说成片”故事板从预览页补齐为可交付的视频生产链路，并让文生图、文生视频、素材再创作、单镜头导出和小说最终成片统一支持明确的清晰度档位。

最终流程：故事板确认 → 批量生成分镜 → 逐段质量处理 → 自动拼接 → 自动字幕 → 字幕校对 → 合成与下载。

## 产品档位

### 快速导出

- 保留模型原始输出，避免额外超分等待。
- 使用 FFmpeg 统一画布、帧率、音频采样率和编码参数，保证可拼接。
- 页面展示原始分辨率和最终导出分辨率，不宣称 AI 1080p。

### 高质量 1080p（小说成片默认）

- H3、LTX、素材视频及最终拼接片统一进入 SeedVR2 3B FP16 质量处理。
- 横屏输出为 1920×1080，竖屏输出为 1080×1920。
- 保持原始宽高比；比例不一致时使用裁切或安全区填充，不进行非等比拉伸。
- 页面明确展示“原生分辨率 → AI 超分 → 最终输出分辨率”。

### 极致质量

- 预留 SeedVR2 7B FP16 配置，不设为默认，也不在本期公开入口。
- 仅在独占 GPU、短片和人工验收场景启用，防止三分钟小说成片耗时失控。

## 模型与基础设施

- 服务器为 RTX 5090 32GB、94GB 内存、约 1.6TB 可用磁盘。
- 使用官方 `ComfyUI-SeedVR2_VideoUpscaler`，默认模型为 SeedVR2 3B FP16。
- SeedVR2 作为后处理任务运行，不与 H3/LTX 同时驻留并占满显存。
- GPU 队列串行调度“生成”和“超分”任务；每次切换前卸载不再使用的模型并清理 CUDA 缓存。
- 任务状态必须包含：排队、生成中、超分中、拼接中、字幕中、完成、失败、已取消。
- 每个镜头保存独立产物和状态；失败重试从当前阶段继续，不重复消耗已成功镜头。

## 小说成片界面

故事板生成后显示固定操作区：

1. 编辑镜头文案、图像提示词、动态提示词、时长和字幕。
2. 选择横屏或竖屏，以及快速导出或高质量 1080p。
3. 点击“生成全部镜头”，展示总进度和逐镜状态。
4. 已成功镜头可以预览、单独重试和替换。
5. 全部镜头就绪后自动进入拼接；用户也可手动点击“生成成片”。
6. 自动生成字幕后进入校对区，可修改文字和起止时间。
7. 点击“合成最终成片”，输出带字幕和不带字幕两个版本。

生成历史保存项目、故事板版本、镜头产物、字幕、清晰度档位、最终视频和错误信息。

## 分镜生成

- 智能改编按 1–3 分钟目标拆分；完整原文按章节和语义连续性拆镜。
- 每个镜头生成独立图像提示词、动态提示词、旁白/对白字幕和目标时长。
- H3/LTX 仅使用其真实支持的输入：提示词和单张首帧；不向后端伪传尾帧或多参考图。
- 支持尾帧/参考图的云模型继续保留相应入口。
- 长文本不得直接作为单个模型提示词；先拆镜，再对单镜提示词做长度约束和润色。

## 拼接与字幕

- 后端使用 FFmpeg concat/filter graph 进行拼接。
- 拼接前统一目标尺寸、像素格式、帧率、时间基和音频参数。
- 没有音频的镜头补静音轨，避免拼接时音画时间轴断裂。
- 字幕优先使用故事板中的旁白/对白，生成带时间轴的 SRT/ASS。
- 用户上传或生成的配音存在时，以实际音频时长重新对齐字幕；无配音时按镜头时长分配。
- 默认字幕使用安全区、描边和阴影，横竖屏分别采用不同字号和底部边距。
- 最终输出 H.264 MP4、AAC 音频，同时保存 SRT 字幕文件。

## 全链路 1080p 规则

- 文生图：请求模型可支持的最高安全尺寸；结果不足目标尺寸时进入图像超分，再送入视频模型。
- 文生视频：先按模型安全尺寸生成，再根据所选档位决定是否进入 SeedVR2。
- 素材再创作：原视频不足目标尺寸时进入 SeedVR2；已达到目标尺寸时允许跳过，避免重复生成纹理。
- 小说镜头：每段在拼接前完成质量处理，最终成片再做一次编码尺寸校验，不重复 AI 超分。
- 最终导出用 `ffprobe` 校验宽、高、时长、编码和音轨；不满足目标即标记失败，不显示“已完成”。

## 错误处理

- 显存不足：卸载模型后重试一次；仍失败则降低批次/启用分块，不自动降回普通 Lanczos 并冒充高质量模式。
- 某镜头失败：保留其他成功镜头，显示失败原因和“仅重试此镜头”。
- 超分失败：用户可选择快速导出原始质量，但必须明确标记为非 AI 1080p。
- 拼接或字幕失败：保留分镜视频并允许从相应阶段继续。
- 服务重启：从持久化任务状态恢复，不把运行中任务误报为完成。

## 验收标准

- 四类入口均能选择快速导出或高质量 1080p，小说成片默认高质量。
- 横屏成片经 `ffprobe` 为 1920×1080；竖屏为 1080×1920。
- 至少三镜头真实生成后可以自动拼接，音画连续且顺序正确。
- 自动字幕可见、可编辑、时间轴正确，并可下载 SRT。
- 输出同时包含带字幕和无字幕 MP4。
- H3/LTX 不支持的尾帧/参考图点击后给出真实能力提示。
- GPU 队列不会让 H3/LTX 与 SeedVR2 同时占满显存；失败可阶段续跑。
- 自动化测试、前端生产构建、后端接口测试、线上健康检查和真实短片验收全部通过后才视为完成。

## 非本期范围

- 不把 FlashVSR 作为生产主链路；RTX 50 系官方兼容性尚未确认。
- 不默认开放 SeedVR2 7B。
- 不在本期实现多人协同剪辑、复杂转场模板或专业时间线编辑器。
