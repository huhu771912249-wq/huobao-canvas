# 火宝视频创作中心设计

## 目标

在现有无限画布之外增加独立的顶层“视频创作中心”，让用户无需理解节点即可完成文生图、文生图加视频、素材再创作和小说成片，同时完整保留现有功能与项目数据。

## 设计依据

- 采用 Adobe Firefly 的低门槛工具入口：图片、视频和音频分开进入，低频参数折叠。
- 采用 LTX Studio 的长片生产结构：脚本解析、人物与场景、动态故事板、逐镜头生成、时间线和声音设计。
- 采用 Runway 的素材管理结构：上传与生成素材统一归档、按项目复用、保留生成参数与来源。

## 顶层导航

新增 `/video-studio`，包含三个工作区：

1. 快速创作
   - 文生图
   - 文生图加视频
   - 上传附件后自动识别工作流
2. 小说成片
   - 智能改编 1–3 分钟
   - 完整原文长片
   - 故事板、逐镜头编辑、时间线、旁白、对白、字幕、音乐和最终合成
3. 素材再创作
   - 图片、视频、TXT、Markdown、DOCX、PDF 上传
   - 人物、场景、道具、品牌和普通素材分类
   - 素材引用、来源、生成参数、项目和下载管理

## 兼容保留硬约束

以下现有能力不得删除、改名失效或丢失数据：

- 首页和 `/canvas/:id?` 无限画布
- Text、Image、ImageConfig、Video、VideoConfig、VideoBatch、LLMConfig 节点
- TextOverlay、MaterialVariation、DspCreativeLibrary、DspCreativeTaskCenter 节点
- H3、LTX、FRW、SCAIL-2、外部视频模型和现有 API 设置
- 批量广告尺寸、GIF/MP4、背景替换、素材变化、DSP 导入和任务状态
- LTX 音频、中文字幕轨、最终 MP4 合成
- 本地项目、最近项目、画布连接关系和现有素材 URL

新页面只调用和编排现有 API；结果可一键“送入画布”，旧画布也可打开新页面创建的项目。

## 附件智能识别

上传后先检测类型和大小，再进入对应解析器：

- 图片：识别人物、场景、构图和可用画幅。
- 视频：读取时长、比例、编码和关键帧，作为参考、驱动或待编辑素材。
- TXT/Markdown：按编码解码并提取标题、章节和正文。
- DOCX：读取段落、标题层级和表格内文本。
- PDF：提取文本层；扫描件返回明确提示，不伪装成已识别。

解析完成后显示“识别结果、采用的工作流、预计镜头数、预计成片时长”，用户确认后才批量消耗模型任务。

## 长文和提示词策略

原文不会直接发送给单次视频模型。系统建立四层数据：

1. 文档层：章节、人物、地点、事件和风格总纲。
2. 场景层：场景目的、出场人物、旁白、对白和连续性状态。
3. 镜头层：3–5 秒镜头、景别、机位、动作和首尾帧。
4. 模型层：按 H3/LTX 限制生成不超过 1000 字符的专用提示词。

文生图提示词描述主体、环境、构图、光线、风格和一致性引用；图生视频提示词只强调动作、镜头运动和时间变化，避免重复描述首帧已经确定的外观。

智能改编模式保留主线、人物关系、转折和高潮，将目标控制在 1–3 分钟。完整原文模式按旁白和对白长度自动估时，不承诺模型单次生成长视频，而是逐镜头生成后拼接。

## 状态与失败恢复

- 文档解析、剧本生成、分镜、图片、视频、声音、字幕和合成分别记录状态。
- 单镜头失败可重试或换模型，不重跑整个项目。
- Prompt 超限在提交前拦截并自动重写，不再把上游 422 原文堆到结果节点。
- 每个结果保留输入、模型、提示词版本、素材引用、错误原因和重试记录。
- 页面刷新或服务重启后，从后端任务状态恢复，不依赖浏览器内存。

## 验收

- 现有前端测试全部通过，并增加旧路由、旧节点注册和项目读取的兼容测试。
- TXT、Markdown、DOCX、文本 PDF 能解析；扫描 PDF 明确标记需 OCR。
- 超过 1000 字符的输入不会直接提交给 H3/LTX。
- 两种小说模式都能生成故事板，并可只生成选定镜头进行成本可控的试片。
- 生成结果能预览、下载、重试并送入旧画布。
- 公网真实完成登录、上传、解析、分镜、单镜头试片、素材归档和项目恢复。
