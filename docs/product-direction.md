# 后续产品方向：统一创作入口与个人工作空间

本文记录 2026-08-11 已对齐、暂不在当前迭代开发的产品方向，避免后续首页、画板、快捷表单和账号系统继续形成多套互不相通的逻辑。

## 1. 首页信息结构

登录后的首页按下面顺序组织：

1. **智能创作输入**：用户可以输入自然语言，也可以拖入图片、视频、GIF、Logo、字体等素材。
2. **快捷操作**：保留现有单步骤功能表单，例如 AI 作图、视频生成、视频转 GIF、尺寸转换、文字和水印。
3. **画板工作流**：展示官方常用工作流、用户保存的工作流和用户自建工作流。
4. **最近生成**：只展示可继续处理或下载的生成结果，按图片、视频、GIF、音频分类。
5. **最近项目**：用于返回之前的画板继续编辑，不与最近生成混在一起。

任务中心继续作为全局状态入口，不在首页重复制造多个同名入口。

## 2. 智能入口的选择逻辑

系统根据用户输入和拖入素材推荐执行方式，但最终选择权保留给用户：

- 单一步骤需求优先推荐快捷操作，例如“把这个视频转成 GIF”。
- 多步骤需求优先推荐画板工作流，例如“文生图后生成视频，再转 GIF、加水印并导出”。
- 意图不明确时同时提供“快速处理”和“打开画板”两个选项。

第一阶段只从经过验证的节点和工作流模板中匹配、复制和连接，不让 AI 任意生成未知节点。创建前展示工作流摘要；只有用户确认后才提交消耗模型或 GPU 的任务。

快捷操作不是独立的数据孤岛。每次处理都必须进入统一的项目、任务和素材记录，并提供“在画板中继续处理”。使用保存的工作流时复制出新项目，不直接修改模板。

## 3. 素材驱动的工作流

用户可以把自己的素材拖入智能输入区。例如拖入视频和 Logo，再输入“转成竖屏 GIF 并加品牌水印”，系统可以推荐：

`视频输入 → 尺寸适配 → 视频转 GIF → 添加水印 → 素材导出`

缺少必要素材时，优先允许用户从本人保存的素材或预设中选择，也可以上传新素材或跳过可选节点。进入画板后，所有节点仍可独立移动、增删、替换和重新连线，不把流程写死。

## 4. 个人账号工作空间

后续接入新的鉴权和账号方案时，每个账号拥有相互隔离的个人工作空间，至少包括：

- 上传的图片、视频、GIF、Logo 和字体；
- AI 生成的图片、视频、GIF 和音频；
- 画板项目、任务记录与最近生成；
- 自建、保存和收藏的工作流；
- 水印、文字样式和导出参数预设。

隔离必须由后端数据归属和文件访问共同保证，不能只靠前端筛选。项目、素材、任务、工作流和预设都要记录所属账号，默认仅本人可访问。浏览器本地缓存只保存当前项目 ID、界面状态等轻量数据，不作为账号数据的唯一存储。

团队素材库、工作流分享和多人项目协作留到个人隔离稳定之后再开发。

## 5. 前端统一原则

- 画板是多步骤创作与继续编辑的核心工作空间。
- 首页负责开始创作、选择工作流和回到最近内容。
- 快捷功能适合单步骤处理，但结果可以一键进入画板。
- 复杂节点在画板上保留摘要和常用操作，详细参数使用统一详情面板或带项目上下文的独立编辑页。
- 同一个结果在画板、任务中心和最近生成中使用一致的状态与操作：预览、继续处理、保存素材、下载和定位原项目。
